常见问题

需要花钱吗？

软件完全免费。AI 功能需要你自己填一个模型 API Key（比如 DeepSeek，充几块钱能用几十次），不用 AI 功能也能拖积木编程。

支持什么模型？

所有兼容 OpenAI 格式的接口都能填：DeepSeek、通义千问、Kimi、OpenAI、本地 Ollama……改一下接口地址就行。

我的代码/程序会上传吗？

不会。积木程序存在你自己电脑上，只有你让 AI 帮忙的时候，当前那段文字才发到你配置的模型接口。

和 Scratch 有什么区别？

Scratch 是网页版、要上传作品；fruit编程 是 Windows 桌面软件，AI 能直接替你搭积木、跑程序，还能生成 Python 代码。

不会编程能用吗？

能。你只要用中文说想做什么，AI 负责搭积木。你也可以自己拖积木玩。
